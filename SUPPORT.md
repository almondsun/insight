# Support

Choose the channel that matches your request. This keeps questions answerable and sensitive reports private.

## Usage questions

Search or start a [GitHub Discussion](https://github.com/almondsun/nivune/discussions) for installation, Instagram export, workflow, or general usage questions. Read [Getting Started](docs/GETTING_STARTED.md), the [User Guide](docs/USER_GUIDE.md), and [Troubleshooting](docs/TROUBLESHOOTING.md) first.

## Reproducible bugs

Use the structured [bug report form](https://github.com/almondsun/nivune/issues/new/choose). Include:

- Nivune version or commit.
- Windows, macOS, or Linux version and architecture.
- Expected and actual behavior.
- Minimal reproduction steps using sanitized data.
- Sanitized error text when relevant.

GitHub Issues are public. Never attach or paste a real Instagram archive, username list, SQLite database, report, login secret, personal local path, or screenshot containing account data.

## Feature proposals

Use the feature proposal form from the [new issue page](https://github.com/almondsun/nivune/issues/new/choose). Explain the user problem, desired outcome, privacy implications, and alternatives. A proposal does not create a release commitment.

## Security vulnerabilities

Do not open a public issue. Follow the private process in [SECURITY.md](SECURITY.md), particularly for archive parsing, path traversal, local file access, data exposure, dependency compromise, or future Fame protocol boundaries.

## Instagram account support

Nivune is an independent project and cannot help recover an Instagram account, change relationships, appeal moderation decisions, or provide Meta customer support. It does not connect to Instagram accounts.
